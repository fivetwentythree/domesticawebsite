# Domestica website

This repository is a static Domestica export ready for GitHub Pages.

GitHub Pages should be configured to publish from the `main` branch, `/ (root)` folder. The root folder must contain `index.html`, `assets/`, and `.nojekyll`.

## SEO deployment checklist

- GitHub Pages URL used in metadata: `https://fivetwentythree.github.io/domesticawebsite/`.
- If you add a custom domain, update the canonical URL, Open Graph URL, structured data URLs, `robots.txt`, `sitemap.xml`, and `llms.txt`.
- After deployment, verify the site in Google Search Console.
- Submit `https://fivetwentythree.github.io/domesticawebsite/sitemap.xml` in Search Console.
- Create or claim the Google Business Profile for Domestica Hobart and set the website, phone number, service area, photos, and business category there.
